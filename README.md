# Thanusuya Sri S - Portfolio Website

This package contains a clean, formal, and responsive portfolio website designed for a Software Engineer (Java / Backend specialist).

## Included Files:
- `index.html`: Fully structured, semantic HTML5 markup containing all profile information, work experience, projects, skills, education, and certifications.
- `style.css`: Clean, professional corporate design featuring an executive slate & navy palette, clear typography, and responsive mobile-ready layout.

## How to Test Locally:
1. Extract this ZIP file.
2. Double-click `index.html` to open it directly in any web browser.
